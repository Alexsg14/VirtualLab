Virtual Lab - version 2026-11-17

El proyecto esta directamente en la raiz del repositorio.
Para ejecutar: instalar Node.js 24 LTS y abrir Iniciar_laboratorio.cmd.
Alternativa: ejecutar npm ci y npm run dev desde la raiz.
Para compilar: npm run build. La web se genera en dist/.
La carpeta dist necesita servirse por HTTP; no abrir index.html con doble clic.
GitHub Pages requiere configurar el despliegue; subir el codigo no publica la web automaticamente.
La auditoria de densidad esta en .tools/density-audit/. Los Excel originales no son necesarios para ejecutar la web.
